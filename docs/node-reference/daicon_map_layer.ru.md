# DaiconMapLayer

![daicon_map_layer.png](../assets/images/nodes/daicon_map_layer.png)

**DaiconMapLayer** — это автономная нода `TileMapLayer` со встроенным собственным 3D-ядром `GridMap`.

В отличие от многослойного `DaiconMap`, она управляет ровно **одним слоем тайлов**. Это идеальный выбор для изолированных элементов уровня: съемных крыш, мостов, разрушаемых островков или декоративных навесов, требующих индивидуального контроля или отдельного шейдера.

---

## Особенности

* **Автономное ядро:** Имеет собственный экземпляр `GridMap`, независимый от других слоев.
* **Изолированный Z-Index:** Высота слоя в 3D рассчитывается строго из собственного `z_index` ноды:
   $$\text{Позиция в 3D} = (\text{X}_{\text{тайла}}, \ \text{z\_index} - 1, \ \text{Y}_{\text{тайла}} + \text{z\_index})$$
* **Идеально для силуэтных шейдеров:** Поскольку это отдельная нода, её можно напрямую передать в список `shader_target_nodes` корневого узла `Daicon`, чтобы крыша или стена просвечивалась при заходе игрока.
