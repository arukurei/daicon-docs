
# Начало работы

![title.png](../assets/images/title.png)

**Daicon** — это плагин для Godot для создания 2.5D игр.

Принцип его работы заключается в использовании настоящего 3D-пространства для перемещения и взаимодействия двумерных объектов. Таким образом происходит симуляция трехмерной объемной глубины окружения, сохраняя легкость и визуальный стиль 2D-графики.

Аддон предоставляет разработчику набор специализированных нод и инструментов, объединяющих возможности 3D и 2D в единый удобный рабочий процесс.

---

## Установка

### - **Godot Asset Library** <small>(рекомендуется)</small>

Плагин доступен в официальной библиотеке ассетов:

1. Откройте ваш проект в Godot.
2. Перейдите во вкладку **«AssetLib»** в верхней части окна.
3. Введите в поиске **Daicon** и нажмите **Download** → **Install**.

---

### - **GitHub**

Исходный код проекта и все доступные релизы размещены на **[GitHub](https://github.com/arukurei/Daicon)**.

Ручная установка:

1. Скачайте ZIP-архив с [страницы релизов](https://github.com/arukurei/Daicon/releases).
2. Распакуйте архив и переместите папку `daicon` в директорию `addons/` вашего проекта (путь должен быть `res://addons/daicon/`).
3. В Godot откройте **Проект** → **Настройки проекта** → вкладка **Плагины**.
4. Поставьте галочку **«Включить»** напротив **Daicon**.

---

### - **Itch.io**

Вы также можете скачать релизы на странице **[Itch.io](https://alkrei.itch.io/daicon)**.


> [!TIP] Подключение скрипт-шаблонов
> Для удобной работы с нодами скопируйте содержимое папки `res://addons/daicon/script_templates/` в папку `res://script_templates/` вашего проекта. Это позволит выбирать готовые шаблоны кода при расширении скриптов Daicon-нод.
