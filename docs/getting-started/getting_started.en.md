# Getting Started

![title.png](../assets/images/title.png)

**Daicon** — is a Godot plugin for creating 2.5D games.

Its core principle is leveraging true 3D space to drive the movement and interaction of 2D objects. In this way, it simulates the 3D volume and depth of the environment while preserving the lightness and aesthetic style of 2D graphics.

The addon provides developers with a suite of specialized nodes and tools, uniting 3D and 2D capabilities into a single, comfortable workflow.

---

## Installation

### - **Godot Asset Library** <small>(recommended)</small>

The plugin is available in the official Asset Library:

1. Open your project in Godot.
2. Navigate to the **«AssetLib»** tab at the top of the editor.
3. Search for **Daicon** and click **Download** → **Install**.

---

### - **GitHub**

The open-source repository and all release packages are hosted on **[GitHub](https://github.com/arukurei/Daicon)**.

Manual installation:

1. Download the ZIP file from the [Releases](https://github.com/arukurei/Daicon/releases) page.
2. Extract the archive and move the `daicon` folder into your project's `addons/` directory (path should be `res://addons/daicon/`).
3. In Godot, open **Project** → **Project Settings** → **Plugins** tab.
4. Check the **«Enable»** box next to **Daicon**.

---

### - **Itch.io**

You can also download releases from **[Itch.io](https://alkrei.itch.io/daicon)**.

> [!TIP] Enabling Script Templates
> For the smoothest development workflow, copy the contents of `res://addons/daicon/script_templates/` into your project's `res://script_templates/` directory. This will allow you to select ready-made starter scripts whenever you extend Daicon nodes.
